# Estruturas de Dados e Rede Social em C

Repositório dedicado a implementações práticas de estruturas de dados e desenvolvimento de sistemas em linguagem C.

## 🚀 Projeto em Destaque: Rede Social (Confessions)

Aplicação desenvolvida em C localizada na pasta `ED_P3 Rede Social/Confessions`, que simula as funcionalidades essenciais de uma rede social aplicando conceitos de estruturas de dados, manipulação de memória e fluxo de informações.

### Funcionalidades
- Cadastro e gerenciamento de usuários
- Conexões/amizades entre perfis
- Publicação e visualização de interações
- Executável (`.exe`) compilado disponível diretamente na pasta do projeto para testes imediatos

### Como executar
1. Acesse a pasta **`ED_P3 Rede Social/Confessions`** no repositório.
2. Baixe e execute diretamente o arquivo `.exe` disponível na pasta, **ou** compile os arquivos-fonte manualmente via terminal:
   ```bash
   cd "ED_P3 Rede Social/Confessions"
   gcc *.c -o confessions
   ./confessions
